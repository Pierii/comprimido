# Comprimido

**Conjunto de ferramentas de código aberto para manipulação de arquivos, com processamento local e sem envio de dados a terceiros.**

🌐 **[Conferir o Comprimido](https://pierii.github.io/comprimido/)**

## Sobre

O Comprimido é um projeto de ferramentas para trabalhar com arquivos diretamente no navegador. A primeira ferramenta disponível é a compressão de arquivos PDF.

O projeto está em desenvolvimento e novas funcionalidades serão adicionadas futuramente.

## Tecnologias

* HTML
* CSS
* JavaScript
